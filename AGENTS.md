# Instruções do projeto

- Ao concluir alterações solicitadas, executar verificações apropriadas, criar commit e fazer push para `origin` (GitHub). O usuário pediu que o remoto permaneça atualizado; não entregar somente um ZIP.
- Preservar o remoto `sites`. Usar Netlify para a publicação atual.
- Atualizar README.md e HANDOFF.md quando houver mudança de comportamento ou publicação.
- Gerar jaiara-moveis-netlify.zip a partir do conteúdo de dist/ quando necessário para publicação manual. O ZIP é artefato local e não deve entrar no Git.
- Não versionar senhas, tokens administrativos, capturas de tela ou dados temporários de teste.
- Registrar claramente se uma alteração ainda não foi publicada no Netlify.
